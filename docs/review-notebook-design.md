# 复习本重设计方案

状态：第一期已实现。目标是把原错题本升级为能主动收集重点、保留收藏、安排间隔复习的个人学习库。继续保持纯前端、浏览器本地数据及 JSON 备份。用户已授权平滑升级：上一版完整词卡自动转换，原始快照保存在升级前备份中，设置页可下载；当前导出 v3，支持导入 v2。

## 1. 产品定位

导航改名为「复习本」，原 `/wrong-words` 路由继续承载页面。「错题」成为筛选项，不再决定一个词能否进入复习本。

三个入口汇入同一词条：练习答错自动加入复习；用户手动「加入复习」；用户「收藏」保存重点。每词只有一份复习状态，收藏、加入来源和错题历史可以同时存在。

收藏与复习独立：收藏不自动产生到期任务，界面提供「收藏并加入复习」快捷操作。取消收藏不退出复习，暂停复习不取消收藏。手动加入指从现有词库挑选词或短语，不包含自由编写词条；自建词条可后续独立设计。

## 2. 页面结构

页头主区展示「今日待复习」，显示到期总量及其中逾期量；主按钮「开始今日复习」。默认每轮 20 词，完成后可继续下一轮，20 是分批大小，不限制当天总量。首页及页头徽标显示待复习数量，收藏数留在复习本内。

三个主视图：

- 今日：全部已到期的学习中词条，逾期词属于到期集合的子集。无到期任务时显示下次到期时间，仍可提前练习。
- 全部：收录的全部词条，可叠加筛选「收藏」「曾答错」「手动加入」，以及状态「学习中 / 已稳固 / 已暂停」。来源筛选是交集，词条不会重复显示。
- 收藏：所有收藏词，无论是否正在复习。未加入计划的收藏词提供「加入复习」，支持多选批量加入。

列表支持英文与释义搜索、词书/单元过滤；搜索和筛选后再分页，每页最多 50 条。今日按逾期优先、到期时间从早到晚、再按错误次数排序；全部默认按最近收录，收藏按最近收藏。

词条主要显示：英文、释义、收藏状态、到期时间（现在 / 今天 / 明天 / 具体日期），次级信息显示阶段和错误次数。详细历史、来源和笔记收进词条详情。不要在每行堆满按钮。

行内操作：可聚焦的收藏按钮、一个与状态对应的主操作（加入复习 / 暂停 / 恢复）、更多菜单（笔记、重新学习、从复习本移除）。移动端重要操作带文字，其他操作有可访问名称。删除与批量危险操作需要确认。

预习页每词提供收藏和加入复习；练习页提供「重点关注」入口，但普通默写作答前不泄露英文；完成或揭晓后再展示完整收藏操作。结果页提供「收藏本轮错词」。复习本的「添加重点」打开词库搜索对话框，支持选词、批量添加与简短笔记。

## 3. 间隔复习：采用可解释的阶梯计划

“艾宾浩斯”作为间隔复习的产品表达，不宣称有适合所有人的精确遗忘曲线。第一版采用确定性的阶梯算法，方便理解、测试和调整；不同时引入 SM-2 或 FSRS 的另一套调度状态。

首次答错或手动加入：立即到期，等待第一次有效回忆。随后每次独立、无提示、首次答对，按间隔 1 天、2 天、4 天、7 天、15 天、30 天逐级安排。间隔从实际成功时刻计算，按经过时间存储；「今天」按本地自然日展示，跨时区只改变显示，不重复安排任务。

阶段 0 表示尚未通过一次有效回忆；通过后阶段 1，下次为 1 天后；依次到阶段 6，下次为 30 天后。在阶段 6 的到期复习再次成功后进入「已稳固」，停止自动到期任务，仍保留词条、收藏与统计。

不同作答结果：

- 无提示首次正确：只有已到期且本轮未判定失败的词才升一级。
- 打错后修正、Esc 看答案、主动提示：都按「需要重学」，阶段回到 0，10 分钟后到期。无需在当前轮反复插入同一词。
- 跳过：本轮移出待答队列，学习计划及历史不变，不移除收藏，不算成功或失败；其到期任务依然存在。
- 提前练习：答对只记录练习，不升阶段或推迟到期；答错则回到重学阶段。收藏但未加入计划的词，提前练习答对不自动加入，答错自动加入。
- 同轮同词多个释义：复习本每词只考一次，提示并列全部释义；普通练习若同词有多题，失败优先，同轮后续答对不能抵消失败或连续升级。

复习默认普通默写、无首字母提示，支持主动提示但会标记重学。听写和例句作为「额外练习」入口，第一版不作为通过单词长期记忆阶段的证据；其中的失误仍进入错题历史和重学。这避免例句变形与整词回忆混算。

暂停由用户主动操作，停止自动任务；用户再次实际答错会恢复学习并立即进入重学，结果页明确提示重新加入。已稳固词再次答错同样回到阶段 0。取消收藏、暂停、已稳固、删除是不同动作，不能互相代替。

## 4. 复习会话语义

开始复习时对本轮 20 个词的 ID 和待更新版本做快照，不清空复习本，不消耗尚未回答的到期任务。用户中途退出后，仅已作答的词更新计划；未答及跳过词仍到期。应用内前进后退沿用现有单例续做；整页刷新重新按当前到期任务开局，不承诺恢复逐题输入。

本轮汇总展示：独立答对、需要重学、跳过、仍到期数量，以及本轮带来的下次复习安排。当前牌组错误率与历史到期状态分开计算。

队列不因时间经过或后台更新在练习中突然重排；新的到期词进入下一轮。保存失败保持内存状态及待保存任务，沿用 SaveStatus 提示。纯前端无法保证浏览器被强制终止时零数据丢失，应尽快落盘而不是长时间攒批。

## 5. 数据模型与工程边界

新建 `zjueh.review-notebook`，以当前 `english` 身份为 key，保持既有按词统计契约。词条保存完整 WordEntry 快照及所有已知来源 bookId/unitId，不用当前某一个 SenseCard 的单释义代表全词；来源重复需去重，词书来源靠加载时携带，不能由词头猜测。词库中文释义或例句变化不重置学习进度。

建议 ReviewItem 字段：word、origins、addedAt、updatedAt、favoriteAt（null 表示未收藏）、manuallyAddedAt、firstWrongAt、note，以及可为空的 schedule。schedule 包括 status（active / consolidated / paused）、stage（0..6）、dueAt、lastReviewedAt、lapseCount、revision。收藏但未加入计划的词 schedule 为 null。收藏、错误来源、手动来源均不互斥。

单词作答次数与错误次数继续由 word-stats 负责，每日统计继续由 day-stats 负责，避免在复习本内复制一套相同计数。调度历史独立记录 eventId、会话 ID、word ID、时间、结果、前后阶段、前后 dueAt 和提示使用情况；同一事件重复提交不能多次推进。每词最多保留最近 30 条调度事件，保留累计 lapseCount。

新建 `lib/review.ts` 承载调度纯函数、到期判定、筛选及队列构建。GameEngine 负责调用并通知订阅；存储 schema 校验、默认值、保存放在 storage.ts；持久化继续用 persistence.ts 按键合并。视图走 hooks，不在渲染中读取 localStorage。

Session 增加 reviewScope（due / selected / extra）及 selected IDs，URL 仅携带范围与选项；个人词条、笔记、完整计划及逐题输入不放进 URL。通过 URL 请求当前浏览器不存在的词需给出明确状态，不能凭分享链接恢复他人私人数据。

已稳固词默认排除常规学习，可用「包含已稳固」选项主动再练；暂停仅暂停复习计划，不影响常规词库练习。取消稳固用「重新学习」回到阶段 0，不伪造一次错误。原「已掌握」按钮及永久排除含义由新状态与明确选项替代，相关设置、URL、帮助与测试同步修改。

## 6. 现有数据与备份：实施前必须决定

仓库当前明确拒绝旧 schema，不允许读取迁移旧结构。新增 schema 会涉及旧 wrong-words / mastered 的退出，不能直接清空现有用户记录，也不能悄悄增加迁移路径。

建议把「允许一次显式升级」列为单独产品决策：用户确认后，旧错题变为立即到期的 active 词，旧已掌握变为 consolidated，统计与偏好保留，原备份先导出。只有明确改变仓库当前策略后才实现；未确认前仍按当前 schema 规则工作。

如果继续严格拒绝迁移，发布前必须提供旧版备份出口、清楚说明新版本兼容范围，并由用户主动建立新复习本。不能把这种损失数据的路径视为默认可接受方案。

新键加入 BACKUP_KEYS；完整备份包含计划、收藏、笔记及调度历史，导入前先落盘待保存更新，严格校验阶段/日期/引用关系与容量，导入后刷新引擎。备份版本随契约升级，旧版本是否支持由上面的决策统一确定。

## 7. 分期与验收

第一期就交付完整主链路：统一复习本、收藏/手动加入、今日到期、阶梯调度、无提示复习、暂停与稳固、搜索/分页、备份和保存错误处理。不要先做收藏却仍让开始复习清空词条。

第二期再增加批量管理、笔记强化、日历和复习负担概览；第三期依据使用反馈评估可配置间隔或 FSRS。日历预测基于“之后均通过”的假设，必须明确标注，不能显示成确定任务。

关键验收：收藏与加入计划独立；同词多来源不重复；开始和中途退出不丢词；阶段逐级递进与失败重学准确；提示不升级；跳过不删除；提前成功不延期；同轮失败不能被后续成功覆盖；清空/导入不被旧待保存任务回写；时间与时区边界；暂停/稳固后的失误重新激活；收藏或计划更新失败可重试；390px、键盘操作与 1000 词筛选/分页不溢出。

## 8. 一个完整例子

用户预习时收藏 workforce，暂时不加入计划。后来把它加入复习：立即到期。第一次无提示答对后安排 1 天，接着 2 天、4 天、7 天。某次看了答案：阶段回到 0，10 分钟后重学；收藏仍在，历史仍在。逐级完成 30 天后的验证，进入已稳固；未来常规练习再答错，重新进入重学。
